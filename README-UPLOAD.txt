EXPAND.AD — COMO SUBIR NO GITHUB

1. Abra o repositório do site no GitHub.
2. Clique em Add file > Upload files.
3. Descompacte o arquivo expand-ad-site.zip no seu computador.
4. Arraste para o GitHub o arquivo index.html E a pasta assets inteira.
5. Clique em Commit changes.

A estrutura no repositório precisa ficar assim:

/index.html
/assets/logos/...
/assets/projects/...
/assets/testimonials/...
/assets/igchat/...
/assets/awards/...

IMPORTANTE:
- Não coloque a pasta expand-ad-site dentro de outra pasta se o site for abrir pela raiz do domínio.
- O index.html e a pasta assets devem ficar lado a lado.
- Se usar GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root) > Save.
- Se o repositório já estiver publicado por Vercel, Netlify ou Cloudflare Pages, basta fazer o commit; o deploy normalmente atualiza sozinho.
